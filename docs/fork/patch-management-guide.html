GP200 Studio: Patch Management Guide

How to organise your GP-200's patches from the PATCHES slide-out (copy, cut, paste, swap, reset, undo), and how to set aside bank 64 as a protected workspace, with a short note on why actions take the time they do.

1 How it works (read this first)

One checked step at a time

This editor organises your patches by asking the GP-200 to do one small job at a time, the same way you would from the pedal itself: select a patch, save it to another slot, and so on. Valeton's desktop software isn't available for this kind of work, so the editor talks to the pedal through the steps the pedal already understands.

It's a simple method, and it's reliable. After every change, the editor reads the slot back from the pedal to confirm the change really landed. If anything doesn't match, it stops and tells you exactly what happened and where your patches are.

The trade-off is time. Some actions finish in a moment; others take a few seconds per patch.

What to expect

ActionTypical time

Times vary with the patches involved. Writing a patch takes longest when its effects differ from what the slot held, because the pedal has to load each new effect first.

The spinner

While the editor is working, "Working with the pedal…" appears with a spinning ring under the Patches buttons. Longer jobs also show their progress, for example 2/4. Wait for it to disappear before starting the next action.

Pasting several patches can be stopped partway with the cancel link beside the progress count. The editor finishes the patch it's on, then stops cleanly and tells you which slots were pasted and which are unchanged.

Three rules

  1. Hands off the pedal while the spinner shows. Changing patches, turning knobs or pressing footswitches mid-action can interrupt a step. The editor will notice and stop, but it's better not to make it.
  2. Connect only one editor at a time. Close any other editor tab and Valeton's own software first. Your computer may let several programs talk to the pedal at once, and two editors talking over each other can confuse it.
  3. Back up your pedal first. Before you start, export all of your pedal's patches to your computer with Valeton's official desktop software, so you have a fail-safe copy. Yes, this editor's EXPORT ALL can do the same, but caveat emptor.

2 The PATCHES slide-out at a glance

Click PATCHES in the editor's top row to open the slide-out on the right. Everything in this guide happens here.

Top of the panel

  • active: 63C beside the title shows the slot the pedal is on.
  • FILE works on the patch in the editor: IMPORT .PRST loads a patch file into the editor and plays it on the pedal, then asks whether to save it into the slot the pedal is on; EXPORT .PRST downloads the editor's patch; PRINT makes a printable sheet of it.
  • USER IRS lists the cabinet IRs stored on your pedal.
  • The search box finds patches by name or slot, for example "63B".

The patch list

  • The bank column on the left jumps to a bank; All banks shows everything.
  • Each row shows the slot and the patch name. Tags on the right mark special slots: ACTIVE (the pedal's current slot), DEFAULT PATCH (what RESET copies) and SWAP SLOT (where swaps park a patch).
  • When bank 64 is protected, it's shown in red and labelled PROTECTED.
  • Double-click a row to switch the pedal to that patch and open it in the editor.

The right-click menu

Right-click any patch for the full set of actions: UNDO, REDO, SWAP (with exactly two patches selected), COPY, CUT, PASTE ▸, RENAME, SET AS DEFAULT PATCH, USE FOR SWAP SLOT and RESET. The top lines show what's selected and what's on the clipboard.

An action that can't run right now is greyed out. Hover over it to see why, for example "Copy a patch first". Press Esc to close the menu.

3 Everyday tasks

3.1 Copy and paste

  1. Select the patch or patches to copy (see "Selecting patches" in section 2).
  2. Right-click the selection and choose COPY. The menu's top lines now show what's on the clipboard, for example "clip: 12A–12D · 4 patches".
  3. Right-click the slot where the first patch should go and choose PASTE ▸. The panel says exactly what will be replaced. OVERWRITE is selected; press OK, or double-click the option.

Several patches land in order in the slots that follow; scattered patches land side by side, in slot order. Before each copy, the editor checks that the patch hasn't changed since you copied it; if it has, it asks you to copy again.

PASTE is greyed out if the paste would land on top of the patches you copied, or run past the last slot (64D, or 63D when bank 64 is protected).

3.2 Cut and paste (moving a patch)

  1. Right-click a patch and choose CUT. Nothing changes on the pedal yet.
  2. Right-click where it should go and choose PASTE ▸:
    • OVERWRITE moves the patch there, and resets the slot it came from to your default patch, named "Itza GP-200";
    • SWAP exchanges the two patches instead.

CUT works on one patch at a time and needs a default patch (section 3.5).

3.3 Swap patches

The pedal can only copy one slot onto another, so a swap parks one patch in a swap slot while the other moves. Set one first: right-click a spare slot and choose USE FOR SWAP SLOT (or use PROTECT 64, which makes 64D the swap slot). Whatever is in the swap slot is overwritten by every swap.

PASTE ▸ SWAPCopy one patch, right-click another, choose SWAP
Right-click → SWAPSelect exactly two patches, right-click either one and choose SWAP (it appears just above COPY)
SWAP buttonSelect exactly two patches, then click SWAP
▲UP / ▼DOWNMove the selected patch one slot, swapping it with its neighbour

3.4 Rename

Select a patch, click RENAME (or right-click → RENAME), type the new name (up to 16 characters) and press Enter.

3.5 Reset a slot to the default patch

First choose a default: right-click a patch and choose SET AS DEFAULT PATCH (with bank 64 protected, the default is always 64C; see section 4). Then right-click any slot and choose RESET. After you confirm, the slot holds a copy of the default, named "Itza GP-200".

3.6 Undo and redo

Right-click any patch and choose UNDO or REDO, or press Ctrl+Z / Ctrl+Y (⌘ on a Mac) while the PATCHES slide-out is open. Hover over either menu item to see what it will reverse, for example "Undo: Paste into 61A–61D".

  • Each click is one step, however many patches the action touched.
  • The last 20 actions are kept, until the page reloads or the pedal disconnects.
  • COPY and CUT on their own change nothing, so there's nothing to undo.
  • Swaps and renames undo in seconds. Undoing a paste, reset or save writes the old patches back, which takes about 10–20 seconds per patch.
  • If a slot was changed since (on the pedal, for instance), UNDO refuses rather than wipe that change, and says which slot.

3.7 Saving, importing and refreshing

SAVE PATCHSave the patch you're playing into the ACTIVE slot, like SAVE on the pedal. Quick. (Same as the SAVE TO button at the editor's bottom right.)
SAVE ALLWrite every setting of the editor's patch into the ACTIVE slot, and check it. Use it when you're not sure the pedal matches the editor. About 10–20 seconds.
FILE → IMPORT .PRSTLoads a patch file into the editor and plays it on the pedal, then asks: Save to [slot], or Editor only.
IMPORT→[slot]Puts a patch file straight into the selected slot, after asking.
REFRESHRe-read every patch name from the pedal. Use it after changing patches on the pedal itself.

Playing a patch isn't the same as saving it: the pedal forgets unsaved changes when you switch patches. A patch's new name also reaches the pedal only when it's saved.

4 Protected bank 64

4.1 What it's for

Protecting bank 64 turns its four slots into the editor's own workspace, with two jobs:

  • Nothing runs into it. Actions that fill slots one after another, such as pasting several patches, stop at 63D.
  • Fixed places for the essentials. 64C always holds the default patch and 64D is always the swap slot, clearly labelled.

4.2 PROTECT 64 and RELEASE 64

Click PROTECT 64 and confirm ("This will overwrite and protect patch bank 64"). The editor writes its built-in default patch (every block off except VOLUME) into bank 64, names the four slots, makes 64C the default patch and 64D the swap slot, and shows the bank in red. It takes under a minute and needs nothing set up first.

Anything already in bank 64 is replaced. Export the bank first if you want to keep it.

RELEASE 64 lifts the protection only. The four patches stay as they are, and 64C and 64D keep their roles until you change them.

4.3 The four slots

64A UTILITY-1
64B UTILITY-2		 Spare slots for trying out settings, for example a candidate for a new default
64C ITZA GP-200 (DEFAULT PATCH) The default patch: what RESET copies, and what CUT leaves behind
64D SWAP SLOT Where swaps park a patch; reset to its name after every swap

While the bank is protected:

  • Its names are fixed: RENAME is greyed out, and anything pasted or reset into 64A–64C keeps the slot's name.
  • Nothing is pasted or reset into 64D, and swaps can't move patches in or out of the bank.
  • SET AS DEFAULT PATCH becomes USE FOR DEFAULT PATCH (64C): after you confirm, it copies the chosen patch's settings into 64C, and RESET uses them from then on.

A handy workflow: paste a candidate into UTILITY-1, try it, and when you're happy, right-click it and choose USE FOR DEFAULT PATCH (64C).

4.4 SAVE 64, RESTORE 64 and the change warning

  • SAVE 64 reads 64A–64C, keeps a copy in your browser, and downloads a backup file, "GP200 bank 64 backup date.json".
  • RESTORE 64 asks where from: LAST SAVE (the browser copy, with its date) or FROM FILE…. It writes 64C, 64A and 64B back, rebuilds 64D and protects the bank again. Allow up to a minute.
  • If bank 64's names change on the pedal itself, a blue warning says which slot changed, with a RESTORE 64 button right there.

The browser copy disappears if you clear your browser's data; the downloaded file doesn't.

5 Safety checks and messages

  • Every change is read back from the pedal to confirm it landed.
  • Before a copy, the source is read again to make sure it's still the patch you copied.
  • If something goes wrong partway, the message says what was done and where each patch is, for example "…1C's patch is safe in the swap slot 64D".

Messages you may see

"…has changed since it was read" The patch changed after you copied it. Copy it again, then paste.
"…would run into protected bank 64" The paste would reach bank 64. Start it higher up, or paste fewer patches.
"…changed since, so it wasn't undone" UNDO found the slot changed after the action, and left it alone.
"The pedal kept N value(s) its own way: …" The patch was saved, but the pedal kept the listed settings at its own values (see section 6).

A greyed-out menu item or button always says why when you hover over it.

6 Known limits

  • Written from the editor's copy (SAVE ALL, IMPORT, PROTECT 64, RESTORE 64, and undoing a paste or reset): expression-pedal assignments and a footswitch's saved on/off position can't be set this way, so the slot keeps what it had. Copies made on the pedal (paste, swap, cut, reset) carry them.
  • COMP's Clipping setting stays at its default when written from the editor's copy.
  • Copies store the patch as the pedal plays it: if an expression pedal is controlling a volume or wah, its current position is what's saved.
  • Undo history clears when the page reloads or the pedal disconnects.
  • There's no INSERT (pushing every later patch down a slot): with one checked step per patch it would take minutes. CUT works on one patch at a time.

8 Support

I'm not able to actively support this fork, but I'll address anything I can replicate on my end as quickly as possible.

This web app was built locally on a basic Win11 box running the latest version of Chrome, so the best results will be with that kind of setup. I'm sure other browsers and operating systems will work to some degree, and feel free to let me know what doesn't work for yours, but I can only fix what I can replicate. I'm not a multi-platform programmer by night, just a dude.

Feature requests and bug reports are welcome on GitHub. For a problem, please include the message text, the slots involved, and what you did just before it happened.
